# मातोश्री गृहसेवा - फ्रंटेंड

हे प्रकल्प मातोश्री गृहसेवा साठी एक फ्रंटेंड React अनुप्रयोग आहे. या अनुप्रयोगात घरकामासाठी बुकिंग करण्याची सुविधा आहे.

## प्रकल्प सेटअप

या प्रकल्पाची सेटअप करण्यासाठी खालील चरणांचे पालन करा:

1. **Node.js आणि npm स्थापित करा**: आपल्या संगणकावर Node.js आणि npm स्थापित असणे आवश्यक आहे. [Node.js डाउनलोड करा](https://nodejs.org/) आणि स्थापित करा.

2. **प्रकल्प क्लोन करा**:
   ```bash
   git clone <repository-url>
   cd GRUHASEVA/frontend
   ```

3. **आवश्यक पॅकेजेस स्थापित करा**:
   ```bash
   npm install
   ```

4. **विकास सर्व्हर चालू करा**:
   ```bash
   npm run dev
   ```

5. **ब्राउझरमध्ये अनुप्रयोग पहा**: आपल्या ब्राउझरमध्ये `http://localhost:3000` वर जा.

## प्रकल्प संरचना

- `src/`: मुख्य अनुप्रयोग कोड.
  - `components/`: विविध UI घटक.
  - `pages/`: पृष्ठ घटक.
  - `services/`: API कॉलसाठी सेवा.
  - `styles/`: CSS फाइल्स.
  - `hooks/`: कस्टम हुक्स.
  
- `public/`: सार्वजनिक फाइल्स जसे की favicon.
